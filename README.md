<img src="media/flatmate.svg" width="100%" alt="FlatMate"/>

> **FlatMate** is a Bangladesh-wide property marketplace that connects owners with people who want to rent or buy — with **Mira**, a built-in AI assistant that suggests fair prices for owners and finds matching flats for seekers.

<table>
<tr>
<td width="50%" valign="top">

### ✨ Key Features

* 🏠 Listings for **Rent, Sale, or Rent & Sale**
* 🔍 Search with filters, sorting and pagination
* 🛋️ Detailed property summary + amenities (lift, parking, etc.)
* 🖼️ Multi-image & video upload and management
* 👤 Role-based accounts: **Owner · User (seeker) · Both**
* 📩 Rent / Buy / Inquiry **request workflow** (approve / reject)
* 🔔 In-app **notifications** for owners
* 💬 Owner ↔ seeker **chat**
* ❤️ Favorites / saved properties
* 🚩 **Report a listing** with email alert
* 🔐 Gmail-only sign-up, strong-password policy, bcrypt hashing
* 🔑 Password reset with a **one-time code** (10-min expiry, 5-attempt limit)
* 📊 Owner & seeker dashboards · 📱 responsive UI

</td>
<td width="50%" valign="top">

### 🤖 Mira — AI Property Assistant

**For owners**
* 💵 Price estimate from size, type, city & area (BDT)
* 📈 Low / fair / high price range
* 📍 Location-rate matching: exact area → city → national default

**For seekers**
* 🔎 Flat-finder from budget, purpose, type & size
* 🎯 Ranks active listings against preferences
* 🏡 Returns the best matches with cover photos

### ⚙️ Tech Stack

```text
Frontend  HTML5 · CSS3 · JavaScript
Backend   Node.js · Express.js
Database  PostgreSQL (sessions via connect-pg-simple)
Auth      express-session · bcrypt · RBAC
Uploads   Multer      Email  Nodemailer
AI        Price model + recommendation engine
```

</td>
</tr>
</table>
